# Под одной луной · Адилет & Элина

Мобильное свадебное приглашение на React + TypeScript + Vite с моделью **Jack And Sally** автора **svyART** в официальном Sketchfab Viewer.

## Запуск и публикация

Node.js 22.12+.

```sh
npm ci
npm run dev
```

`npm test` — тесты. `npm run build` — TypeScript и production-сборка в `dist`. `npm run preview` — просмотр сборки. GitHub Actions публикует `main` через GitHub Pages. Относительный `base: './'` поддерживает подпуть репозитория.

## Редактирование

`src/config/wedding.ts` — имена, монограмма, дата, место, программа, тексты, цвета, музыкальные настройки и идентификатор модели Sketchfab. Метаинформация страницы генерируется из этой конфигурации при сборке.

## 3D и прокрутка

- Официальный Viewer SDK `https://static.sketchfab.com/api/sketchfab-viewer-1.12.1.js` управляет iframe с UID `84dfe9166e0946b7a5a6976408483ec1`.
- Исходная позиция камеры берётся из самой модели. Прокрутка обходит пару по кругу вокруг оси Z и слегка приближает камеру; текст плавно переключается между четырьмя разделами.
- «Рассмотреть 3D» включает ручное управление внутри iframe. «Вернуть прокрутку» возвращает управление странице. В обычном режиме iframe не перехватывает свайпы.
- Системный `prefers-reduced-motion` отключает движение камеры и переходы текста.
- При ошибке загрузки API сохраняется обычный iframe и ссылка на исходную модель. Для 3D нужен WebGL, доступ к ресурсам Sketchfab и разрешённые скрипты платформы.
- Текст и форма работают независимо от загрузки 3D. При скрытии вкладки Viewer останавливается.
- Видимые ссылки на название модели, автора и Sketchfab сохранены. Модель не скачивается и не перепаковывается. Прозрачность и платное скрытие элементов платформы не используются.

Источник модели: https://sketchfab.com/3d-models/jack-and-sally-84dfe9166e0946b7a5a6976408483ec1
Автор: https://sketchfab.com/svyART

## Оформление

Ночное небо, состаренная луна, звёзды, изгибы холмов, лиловые тени и золотистые акценты создают атмосферу романтической готической сказки. Декорации выполнены в SVG/CSS. При прокрутке двигаются луна и слои пейзажа; само окружение внутри iframe остаётся авторской сценой Sketchfab.

## Музыка и ответы гостей

Кнопка «Музыка» запускает оригинальную синтезированную минорную миниатюру через Web Audio. Это не саундтрек мультфильма. Звук включается только после нажатия, повторное нажатие выключает его; в скрытой вкладке воспроизведение прекращается. Настройки в `music`, ноты в `src/audio/piano.ts`.

RSVP — тестовая форма: имя и число гостей сохраняются только в localStorage браузера и не отправляются организаторам.

## Основные модули

- `src/App.tsx` — композиция страницы и декоративный пейзаж.
- `src/hooks/useScrollScene.ts` — прогресс, сглаживание и жизненный цикл сцены.
- `src/scene/sketchfabScene.ts` — официальный iframe/SDK, загрузка, ручное управление и очистка.
- `src/scene/sketchfabCamera.ts` — расчёт орбиты камеры.
- `src/scene/timeline.ts` — переходы текста.
- `src/components/` — меню, музыка, разделы и форма.
- `src/style.css` — адаптивный ночной дизайн.

Процедурная свадебная пара и `npm run generate:model` сохранены как отдельные исходники для самостоятельного использования; в текущей странице они не подключены. Three.js используется этими вспомогательными модулями и распространяется по MIT (`THREE-LICENSE.txt`).
