# Белая история · мобильное 3D-приглашение

Рабочий статический прототип в бело-бежевых оттенках. Имена, дата и программа демонстрационные. Пара создана процедурно в Three.js: это стилизованные фигуры, а не восстановление по фото и не фотореалистичные модели из дизайн-концепта.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

`npm test` — проверка переходов и геометрии. `npm run build` — сборка в `dist`. `npm run preview` — просмотр сборки. Открытие index.html напрямую через file:// не поддерживается.

## Что работает

- Нативная прокрутка страницы, вращение настоящей 3D-пары на 360°, плавное появление садовых арок и банкетной локации.
- Четыре секции текста, мобильное меню, навигация по разделам, шкала прогресса.
- Адаптация к узкому экрану и десктопу, safe area, системная настройка уменьшения движения.
- Рендеринг по необходимости: сцена не перерисовывается постоянно в покое, DPR ограничен.
- Читаемый контент при отсутствии WebGL. Шрифты Google Fonts имеют локальные системные замены.
- Тестовая форма: сохраняет имя и количество гостей в localStorage. Она ничего не отправляет организаторам. Реальный сбор ответов требует сервера или подключения сервиса форм.

## GitHub Pages

1. Создайте отдельный публичный репозиторий `wedding-scroll-` с веткой `main`.
2. Загрузите **содержимое** этой папки в корень репозитория, включая `.github/workflows/pages.yml` и `package-lock.json`. Не загружайте `node_modules`.
3. В Settings → Pages → Build and deployment выберите Source: **GitHub Actions**.
4. При необходимости запустите Actions → Publish wedding demo → Run workflow.
5. Дождитесь успешного задания deploy. Точная ссылка появится в его Environment.

`base: './'` в Vite позволяет работать по подпути репозитория. Публикация не требует платного сервера. Готовая папка `dist` также подходит для обычного статического хостинга.

## Структура

- `src/sculpture.js` — фигуры, материалы, архитектура и декорации.
- `src/scroll.js` — чистая функция переходов от прогресса прокрутки.
- `src/main.js` — 3D-рендеринг, камера, DOM, форма.
- `src/style.css` — мобильная композиция и адаптивность.
- `index.html` — контент. Здесь заменяются имена, дата и программа.

## Следующая итерация

Для качества исходного макета замените `createCouple()` на загрузку детальной авторской `.glb` через GLTFLoader и сохраните управление `couple.rotation.y`. Для клиентских проектов используйте модели с правом коммерческого использования. Пока свет и геометрия служат прототипом; визуальная проверка на реальных iOS/Android устройствах обязательна перед коммерческим запуском.

Three.js распространяется по MIT; лицензия входит в npm-пакет и production-сборку Vite.
