# Белая история · Адилет & Элина

Мобильное свадебное приглашение на **React + TypeScript + Vite**, Three.js. Данные демонстрационные, фигурки процедурные и стилизованные, без восстановления по фотографии.

## Запуск

Node.js 22.12+.

```sh
npm ci
npm run dev
```

- `npm run typecheck` — проверка TypeScript.
- `npm test` — сценарии переходов, геометрия и серверный рендер React.
- `npm run build` — проверка типов и production-сборка в `dist`.
- `npm run preview` — просмотр готовой сборки.

## Где редактировать данные

**`src/config/wedding.ts`** — имена, монограмма, дата, место, ссылка на карту, расписание, тексты всех разделов, подписи, цвета и настройки движения. Имена и монограмма задаются отдельно, чтобы поддерживать разные варианты оформления. Цвета оформления применяются через CSS-переменные; материалы 3D-скульптуры находятся в `src/sculpture.js`.

После изменения данных сохраните файл и сделайте commit/push в `main`: GitHub Actions проверит проект и опубликует его через Pages. Заголовок и описание в production-HTML генерируются из этой же конфигурации при сборке.

## Анимация

Одна sticky-сцена занимает экран. Нативная прокрутка управляет поворотом пары на 360°, движением камеры, появлением садовых арок и банкетных декораций. Тексты сменяются через прозрачность, небольшое смещение и размытие. Сглаживание зависит от времени кадра, а не частоты экрана. React не перерисовывает компоненты каждый кадр: меняется только активный раздел, а промежуточные состояния применяются через CSS-переменные.

В покое отрисовка прекращается; в скрытой вкладке кадры не запрашиваются. Есть ограничение DPR, инстансинг цветов и отложенная загрузка Three.js. При размонтировании снимаются обработчики, прекращается цикл и освобождаются GPU-ресурсы. При системном `prefers-reduced-motion` вращение и движения камеры отключаются, контент и локации переключаются без анимированного перехода.

При отсутствии WebGL доступна декоративная резервная композиция; текст, меню и форма продолжают работать. Для оценки 3D нужен браузер с WebGL. Шрифты Google Fonts имеют системные замены.

## Форма

RSVP демонстрационный: ответ хранится только в localStorage данного браузера. Организаторам он не отправляется. Для реальных ответов потребуется API или сервис форм.

## GitHub Pages

В Settings → Pages выбран источник **GitHub Actions**. Workflow `.github/workflows/pages.yml` устанавливает зависимости, запускает тесты, собирает приложение и публикует `dist`. Относительный `base: './'` поддерживает подпуть репозитория `wedding-scroll-`.

Three.js — MIT, текст лицензии в `THREE-LICENSE.txt`. Для качества исходного макета процедурную пару можно заменить детальной GLB-моделью в `src/scene/createScene.ts`.

## Музыка и новая модель

В шапке появилась кнопка «Музыка». После нажатия Web Audio синтезирует оригинальную спокойную фортепианную миниатюру. Это не запись известной песни. Повторное нажатие плавно выключает звук; в скрытой вкладке воспроизведение прекращается. Настройки — `music` в `src/config/wedding.ts`; мелодия — `src/audio/piano.ts`. Автовоспроизведения со звуком нет.

`src/scene/detailedCouple.ts` — стилизованная пара в полный рост, художественно интерпретированная по одному селфи. Это **не фотограмметрия, не точная 3D-копия лиц и не восстановление невидимых частей тела**. Пропорции тела, свадебные наряды и вид со спины придуманы. Оригинальная фотография не включена в репозиторий или модель.

Добавлены глаза и веки, брови, носы, губы, пряди и пучок волос, серьги, фата, складки и шлейф платья, жемчужные украшения, букет, пальцы, жилет, лацканы, бабочка, пуговицы и туфли. `scripts/export-couple.ts` объединяет статические части по материалам и экспортирует настоящую трёхмерную модель в `public/models/adilet-elina.glb`. Перлы используют инстансинг. GLB создаётся автоматически перед dev/build и загружается через GLTFLoader; при ошибке загрузки используется та же процедурная модель.

Скачать модель после публикации: `https://akkunov.github.io/wedding-scroll-/models/adilet-elina.glb`. Для ручного экспорта: `npm run generate:model`.
